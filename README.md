A deadpan one-star review of gravity, an everyday essential, for the
[One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629)
bounty on [make.fun](https://make.fun/r/w3zshnah).

> Gravity has never caught anything I have dropped. It just makes sure it lands face-down and then sends the repair bill.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

The program is deterministic: no network, no clock, no randomness. It writes
the single-line review (119 characters, under the 160-character cap) to
`entry.txt` in the output directory.
